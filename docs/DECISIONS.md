# Decisions

Written 19 Nov 2026, when the Facecard folder became this project (under a working title; named ProBuilds on 24 Nov, D-49, D-50). The Facecard log (6 Nov) is retired; this file starts again at D-01. Claude CLI treats decisions as fixed. To change one, add a new entry that supersedes it. Never edit an old entry.

Kinds: **D-** decided by Chime. **A-** architecture proposal (Claude's call until Chime objects). **L-** lesson carried from Meridian, CenterSpot and Sinima. **O-** open question.
